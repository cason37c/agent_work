# ADR-0001：以控制分支与固定 SHA 交接任务

状态：采纳。日期：2026-10-20。

## 决策

任务状态保存在主分支，代码保存在任务分支；以固定规格 SHA 和实现 SHA 交接。架构师审查并验收后才放行下项，默认顺序执行。

## 理由与代价

另一模型只需读取仓库即可恢复上下文；审查可对应实际实现版本，代码提交不会自行构成验收。控制提交与实现提交分离能避免实施报告、自引用 SHA 和状态合并发生冲突。

代价是一次任务会产生多次元数据提交，控制更新需要普通 push 或通过平台要求的 PR。规则只能规范参与者行为，权限和自动运行需要外部设施。本轮接受这些成本，优先确保交接可追溯。
